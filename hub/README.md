# Hub

The Hub is the small, versioned brain of the system. It owns governance and routing, not the
payload of every project.

```text
hub/
|-- hot.md       Small navigation surface
|-- core/        Rules, sacred boundaries, and toolbox registry
|-- protocols/   Repeatable operating procedures
|-- memory/      Current state and handoff contract
|-- reports/     Durable findings and scans
|-- LOG.md       Meaningful changes
`-- LEARNINGS.md Reusable lessons from failures
```

Keep boot-loaded documents short. Put detail behind links and load it only when required.
