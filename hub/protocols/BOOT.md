# Session boot protocol

Before substantial work, load exactly:

1. `hub/hot.md`
2. `hub/core/SACRED.md`
3. `hub/memory/SESSION_STATE.md`
4. The newest relevant handoff, when continuing earlier work

Then announce the active focus and next step in one line.

Load `hub/core/RULES.md`, a domain `BRAIN.md`, or a skill `SKILL.md` only when the task needs
them. Delegated workers follow only their bounded task brief and do not run the full boot ritual.
