# Sacred boundaries

Never read, print, move, overwrite, delete, publish, or commit these without explicit,
case-specific owner approval:

- credential values, private keys, recovery codes, and local secret stores
- browser profiles, cookies, sessions, wallets, and account state
- canonical memory and irreplaceable personal or business data
- active repositories with uncommitted or unpushed work
- git remotes, deployment credentials, and backup archives

Destructive actions outside this list still require explicit approval and a recoverable plan.
